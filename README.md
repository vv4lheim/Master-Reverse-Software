This project involved software reverse engineering focused on binary analysis, particularly of a Command & Control (C2) component. It allowed me to apply reverse engineering techniques using Ghidra and Binary Ninja to understand the internal behavior of the binary, its communication mechanisms, and its malicious activities. The project also included the analysis of malicious files such as XLS and PDF documents, with macro flow analysis to identify infection chains and execution vectors.

This experience provides a strong foundation for the continuation of my cybersecurity career, especially in the fields of reverse engineering, malware analysis, and threat analysis. It helped me develop a rigorous approach to static analysis, a deeper understanding of malicious software architectures, and attack chains.
